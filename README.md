This is an Employee Tracking System designed to monitor working hours effectively. It functions based on a simple timer mechanism.

* When the Start button is clicked, the timer begins counting.
* When the End button is clicked, the timer pauses.
* The system calculates the total time worked by subtracting the start time from the end time.

This feature allows employers to accurately track how many hours an employee has worked during the day. It's useful for productivity analysis, payroll calculations, and attendance records. The interface is user-friendly and helps maintain work discipline with real-time tracking.
